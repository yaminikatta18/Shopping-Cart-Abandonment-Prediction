    About the Project

    Problem

    Customers add products to their cart but leave without buying, causing lost revenue. Browsing time, products viewed, cart value, previous purchases and discount usage reveal patterns that can flag likely abandonment early.

    Objectives

    • Analyse customer behaviour and the factors behind abandonment
    • Preprocess data and build Decision Tree and Random Forest models
    • Evaluate and compare models, then predict abandon vs purchase
    • Enable timely actions: reminders and personalised offers

    Dataset

    Target variable

    0 = Purchase Completed   1 = Cart Abandoned

    Raw data→Features→Train/Test split→Model→Evaluate→Serve API

    The Algorithms

    🌳 Decision Tree

    Splits data using the feature thresholds that best reduce Gini impurity, following branches down to a leaf prediction. Depth is limited (max_depth=5, min_samples_leaf=20) as pre-pruning to control over-fitting.

    Customer data → Decision rules → Prediction

    
    
    🌲 Random Forest
    
      
    Bagging: 200 trees trained on bootstrap samples with random feature subsets. Votes are averaged, which reduces variance versus a single tree. The out-of-bag score gives a built-in validation estimate.
    
      
    Customer data → Many trees → Combined vote → Cart status
    
      
    –OOB accuracy
    
  
    
  
    Depth vs accuracy (validation curve)
    
  
    Training accuracy keeps rising while test accuracy peaks then falls: classic over-fitting.
